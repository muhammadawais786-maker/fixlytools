How to Pick a Color and Get Its Code

Web designers and developers need the same color in different formats. This tool shows all of them at once and lets you copy the one you need.

  1. Choose a color: Click the color box to open the picker, press Random, or use "Pick from screen" (in Chrome and Edge) to take a color from anywhere on your screen.
  2. Or type a code: Type or paste a HEX code such as #2563EB, an rgb() value or an hsl() value into the box. The other fields update straight away.
  3. Fine-tune with the numbers: Change the R, G, B or H, S, L fields to adjust the color precisely.
  4. Copy the format you need: Press Copy next to HEX, RGB, HSL, CMYK or the ready-made CSS line.
  5. Check readability: The contrast boxes show how readable text in this color is on white and on black.

Frequently Asked Questions

How do I convert HEX to RGB?

A HEX code has three pairs of digits for red, green and blue. #2563EB is 25, 63 and EB in hexadecimal, which are 37, 99 and 235 in decimal, so the color is rgb(37, 99, 235). Type the HEX code into the tool and it shows the RGB value for you.

What is the difference between RGB, HSL and CMYK?

RGB mixes red, green and blue light and is used on screens. HSL describes a color as hue, saturation and lightness, which is easier to adjust by hand. CMYK is the ink mix used in printing.

Is the CMYK value exact for printing?

No. It is a simple mathematical conversion. Real printers use color profiles, so the printed color can look different. Use it as a starting point only.

What does the contrast ratio mean?

It measures how well text stands out from its background, from 1:1 (no contrast) to 21:1 (black on white). WCAG asks for at least 4.5:1 for normal text to be readable by most people, including those with low vision.

Why does Pick from screen not appear?

The eyedropper uses a browser feature that is available in Chrome and Edge on computers. Safari and Firefox do not support it yet.

Can I type a short HEX code like #f0a?

Yes. Three-digit codes are expanded, so #f0a becomes #FF00AA.
