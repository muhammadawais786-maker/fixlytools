How to Encode and Decode Base64

Base64 turns any data into plain letters and numbers so it can be sent safely in places that only accept text, such as JSON, URLs, emails and HTML. This tool does it in your browser.

  1. Paste your input: Type or paste normal text to encode, or a Base64 string to decode.
  2. Press Encode or Decode: Encode to Base64 turns text into Base64. Decode from Base64 turns it back into readable text. Tick URL-safe if the result goes into a web address.
  3. Copy the result: Copy the result, or press "Use result as input" to run another step on it.
  4. Images and files: Open the File or Image tab, choose a file up to 5 MB and copy its Base64 or data URI for use in HTML, CSS or an API.

Key Features

  • Unicode safe: Works with Urdu, Arabic, emoji and every other language, not only English letters.
  • URL-safe option: Produces the Base64URL variant used in tokens and web addresses.
  • Image and file to Base64: Creates the raw Base64 or a full data URI with a live image preview.
  • Forgiving decoder: Ignores spaces and line breaks, accepts data URIs, URL-safe characters and missing padding.
  • Download decoded files: Decode Base64 back into a file when the data is not text.
  • Private: Everything runs in your browser. Nothing is uploaded.

Frequently Asked Questions

What is Base64?

Base64 is a way to write binary data using only 64 safe characters (A to Z, a to z, 0 to 9, + and /). It is used to send images, files and special characters through systems built for plain text.

Is Base64 encryption?

No. Base64 is only a change of format and anyone can decode it. Never use it to hide passwords or private data.

Why is my decoded text garbled or not shown?

The data may not be text, for example an image or a PDF, or it may have been encoded in a different character set. Try "Download decoded file" to save it as a file.

What is URL-safe Base64?

Standard Base64 uses + and / and ends with = signs, which have special meanings in web addresses. URL-safe Base64 swaps them for - and _ and removes the padding, so it can be used in links and tokens.

How do I convert an image to Base64?

Open the File or Image tab, choose the image and copy the result. Keep the data URI prefix ticked to get a string you can paste straight into an img tag or a CSS background.

Why is the Base64 version bigger than the original?

Base64 makes data about one third larger, because it uses four characters to store every three bytes. That is why it is best for small images and icons.

Is there a size limit?

Text has no fixed limit, but very large inputs depend on your device memory. Files are limited to 5 MB in this tool.
