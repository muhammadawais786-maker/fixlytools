Frequently Asked Questions

How long should a strong password be?

Security experts recommend a minimum of 12 characters, with 16 or more being ideal. The longer the password, the exponentially harder it is to crack. For highly sensitive accounts (email, banking), use 20 characters or more.

Should I use symbols in my password?

Yes. Adding symbols like !@#%^&* significantly increases the number of possible combinations, making a brute-force attack much harder. Always enable symbols for sensitive accounts.

Is the generated password stored anywhere?

No. Passwords are generated inside your browser using the Web Crypto API and exist only in memory. They are never sent to any server, saved in a database, or logged in any way.

How do I remember a complex random password?

You should not try to memorise random passwords. Use a reputable password manager such as Bitwarden (free and open source), 1Password, or Dashlane to store your passwords securely.

What is the difference between random and pseudo-random passwords?

Pseudo-random generators use mathematical formulas that can theoretically be predicted. True random generators (like the Web Crypto API used here) use unpredictable sources of entropy, making the output genuinely random and suitable for security use.
