How to Create a Barcode Online

A barcode is the pattern of black lines you see on products, parcels and library books. Unlike a QR code, which is a square of dots, a barcode is read in one direction and holds a short number or code. This generator makes five common types.

  1. Choose the barcode type: Use Code 128 for general codes with letters and numbers, Code 39 for simple capital-letter codes, and EAN-13, EAN-8 or UPC-A for retail product numbers.
  2. Enter your text or number: For EAN and UPC, type the digits. If you leave out the last check digit, the tool adds it for you and tells you if one you typed is wrong.
  3. Adjust the look: Change the bar width, height and colors, and choose whether to show the text underneath.
  4. Download: Save the barcode as a PNG image or as an SVG that stays sharp at any size.

Frequently Asked Questions

What is the difference between a barcode and a QR code?

A barcode is a row of vertical lines that holds a short code or number and is read in a single direction. A QR code is a two-dimensional square that can hold much more data, such as a web address. Use our QR Code Generator for links and a barcode for product or inventory numbers.

Which barcode type should I choose?

Use Code 128 for inventory, shipping and general labels. Use EAN-13 for products sold in most of the world, and UPC-A for the USA and Canada. EAN-8 is for very small packages. Code 39 is an older type used in some industries and libraries.

Can I use these barcodes on products I sell in shops?

The tool creates a correct barcode image for any number, but shops expect official numbers that belong to your company. EAN and UPC numbers are issued by GS1, so register with them (or the national GS1 office) before selling retail products.

What is the check digit?

The last digit of an EAN or UPC number is calculated from the other digits. Scanners use it to detect misreads. Enter one number less and the tool adds the check digit, or enter the full number and it is verified.

Why can my scanner not read the barcode?

Print it large enough with strong contrast (dark bars on a light background), leave blank space at both sides, and do not stretch it. A wider bar setting usually helps with low-quality printers.

Does Code 128 support lowercase letters?

Yes. Code 128 supports uppercase and lowercase letters, digits and symbols. Code 39 supports capital letters only.
