How to Use This Tool

Page numbers make long documents easier to read, print and refer to. Fixlytools adds them to your PDF in your browser and lets you control the position, style and which pages are numbered.

  1. Upload Your PDF: Click "Choose PDF File" or drag a PDF onto the box.
  2. Choose Position and Format: Pick one of six positions and a format such as 1, Page 1, or Page 1 of 10. Set the start number, font size and distance from the edge.
  3. Select Pages (Optional): Leave the pages box empty to number every page, or type a range such as 2-10. You can also skip the first page, for example a cover.
  4. Download: Click "Add Numbers & Download" to save the numbered PDF. Your original file is not changed.

Key Features

  • Six Positions: Place numbers at the top or bottom, on the left, center or right.
  • Three Formats: Plain numbers, "Page 3", or "Page 3 of 10".
  • Custom Start Number: Begin at any number from 0 up, useful when your PDF is part of a larger document.
  • Pages You Choose: Number every page, a range, or everything except the cover page.
  • Handles Rotated Pages: Numbers on sideways pages are turned so they read correctly where the reader sees them.

Frequently Asked Questions

Which number does each page get?

Each page shows the start number plus its position in the file. With a start number of 1, page 4 shows 4. Skipping the first page does not change this, so page 2 still shows 2.

Can I leave the cover page without a number?

Yes. Tick "Do not number the first page".

Can I number only some pages?

Yes. Type a range such as 3-12 in the pages box. Pages outside the range are left as they are.

What if a number overlaps my content?

Numbers are drawn on top of the page. If a page has content close to the edge, increase the distance from the edge and download again.

Can I change the numbers afterward?

The numbers are added as normal text on the page. They are not an editable field, so run the tool again on your original file to change them.

Is my PDF uploaded to a server?

No. Everything is done in your browser and the file never leaves your device. Password-protected PDFs cannot be processed.
